# Lidar-Feature-Saliency-Enhancement

**Lidar Feature Saliency Enhancement** 是一个针对低成本激光雷达（如 RPLIDAR A1）在高噪声环境下几何特征识别精细度提升的研究项目。本项目通过 Python 仿真构建复杂几何场景，探索提升点云特征显著性的算法，旨在解决多机器人 SLAM 地图融合（Map Merge）中的数据关联失败问题。

## 🚀 背景与痛点

多机器人 SLAM 时，需要对每个机器人建的子图进行拼图 `map_merge`，地图融合涉及两个关键步骤：地图对齐和数据关联。[^1] 其中大致分为两种方法：

1. **已知初始位置**：知道每个子图相对于全局地图的相对坐标，只需要对子图进行坐标转换就可以将多个子图拼接。
2. **未知初始位置**：利用地图结构和几何信息来识别可能的匹配项，并基于重叠区域直接合并拓扑地图。

当激光雷达扫描出来的环境几何特征不明显时，`map_merge` 会因为找不到相似的几何特征而"乱拼图"。如果原始扫描数据无法被有效地转换为具有代表性的特征，或者这些特征过于单一（缺乏区分度），那么其"全局统计控制过程"就失去了对比的基础。[^2]

### 传统方法

- PCL 滤波
- 简单角度/距离裁剪（硬阈值过滤）
- 多传感器融合（深度相机补盲）

## 🛠️ 技术架构

项目采用模块化设计，方便扩展不同的传感器模型与增强算法：

- **`core/environment.py`**：基于 OpenCV 的高分辨率栅格地图建模，支持自定义复杂几何体（如五角星柱体）。
- **`core/sensor.py`**：模拟 RPLIDAR A1 的物理特性，包括角度分辨率、量程限制及高斯噪声模型。
- **`main.py`**：主调度程序，负责机器人路径规划（绕圈扫描）与动态可视化。

## 🔬 整体研究思路

```
建立仿真环境
    ↓
设置雷达和被识别物体参数等
    ↓
引入噪声
    ↓
探究提升识别率的方法
    ↓
对比验证
```

## 💡 预想方法

**时序多帧融合超分辨**：用机器人静止时的 3–5 帧低频扫描，融合生成 1 帧高频"虚拟扫描"，突破思岚 A1 物理分辨率限制。

在**单传感器纯 2D 激光**框架下，通过**时序超分辨 / 自适应几何增强 / 置信度加权**，**前置增强**雷达数据的可辨识度，无需修改后端 `map_merge` 算法即可提升拼图成功率。

## 📦 快速开始

```bash
python main.py
```

运行后可得到三个仿真图像窗口：全局轨迹与状态面板、当前扫描帧、增量拼接地图。
